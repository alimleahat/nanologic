# Examples

- `starter-de10lite/`: the starter example (counter on HEX0, switches to LEDs). Opened from the Welcome screen.
- `traffic-light/traffic_light.nlproj`: project file for the reference project (`tests/fixtures/fpga-traffic-light-controller`), with pins mapped for the DE10-Lite and the 1 Hz divider bypassed on the virtual board. The Welcome screen copies the reference sources and this file into Documents/NanoLogic/Examples.
- `traffic-light-export/`: a level 3 Quartus export of the reference project, to open in Quartus Prime Lite 17.1 on a lab PC (generated by `npm run examples:export`).
